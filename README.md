## 🛠️ Local Command Center
Your workspace is equipped with custom PowerShell tools to manage the production environment from `C:\Users\hp\volsim-pro`.

### **Core Scripts**
- `./volsim-command-center.ps1`: The main hub for monitoring and one-key deployment.
- `./volsim-sanity-check.ps1`: Runs a full handshake test between Vercel and Render.
- `./volsim-cleanup.ps1`: Purges junk logs and temporary files to keep builds fast.

## 🚀 Deployment Workflow
To update the entire stack:
1. Make changes to code.
2. Run `./volsim-command-center.ps1`.
3. Select **Option 2** (One-Key Deploy).
4. GitHub triggers Vercel and Render to rebuild automatically.

## 📅 Maintenance
- **Daily Heartbeat**: A Windows Task is scheduled to run the `Sanity Check` every morning at **8:00 AM**.
- **Auto-Wake**: The monitoring script pings Render every 60 seconds to prevent free-tier spin-down.
